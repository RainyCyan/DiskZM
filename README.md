## What is DiskZM

`DiskZM`是多维学习型索引[ZM](https://ieeexplore.ieee.org/document/8788832)的磁盘化版本，其一维学习型索引采用了[PGM_Index](https://github.com/gvinciguerra/PGM-index)的多维变体，并编写了对应的磁盘持久化版本代码
